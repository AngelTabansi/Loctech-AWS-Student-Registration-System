# 🛠️ Phase 04 — Application Development

## 📌 Overview

The fourth phase of the Loctech AWS Capstone Project focused on connecting the Student Registration System application hosted on Amazon EC2 to the Amazon RDS MySQL database.

## 🎯 Objectives

- Connect the backend application to Amazon RDS MySQL.
- Create the students database table.
- Implement CRUD operations: Create, Read, Update and Delete.
- Test the application and database connection.

## 🧰 Technologies Used

- Amazon EC2 — application hosting
- Node.js and Express — backend API
- Amazon RDS MySQL — database
- Apache — web server and reverse proxy
- HTML, CSS and JavaScript — frontend
- PM2 — backend process management

## 🧪 Testing

The application was tested to verify database connectivity and student record management through CRUD operations.

## ✅ Outcome

The goal of this phase was to connect the frontend and backend to the database so student records could be stored and managed persistently.
